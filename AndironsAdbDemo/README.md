# ADB / Windows 坐标工具

运行本目录的 AndironsAdbDemo.exe。

只需复制这个 EXE 即可携带 ADB：内含 Platform-Tools 33.0.2 的 adb.exe、
AdbWinApi.dll、AdbWinUsbApi.dll 和 NOTICE.txt，使用时自动释放到用户数据目录。
ADB path 留空使用内置版本，也可手动指定外部版本。

## ADB 设备

保留连接设备、设备截图、手机坐标取点、框选、ADB 点击、文本和按键功能。
截图区域按设备原始像素输出，与预览窗口大小无关。
网络模式填写 IP:端口后点击 Connect；USB 模式连接数据线、开启 USB 调试，
点击“刷新设备”，选择已连接设备后截图或开启实时预览。首次使用需在手机
允许 USB 调试授权，个别手机仍需厂商 USB 驱动。未授权和离线状态会显示在列表中。

## 实时预览与桌面坐标

三种来源均支持“实时预览”，默认刷新间隔 300ms，可设置 100～5000ms。
间隔是取帧频率上限，实际速度受 ADB 传输、设备编码及画面大小影响；
同一时间只取一帧，不堆积请求。ADB 命令、截图和图像解码不会同步阻塞界面。
取消勾选可冻结画面继续取点、框选；更换来源、设备或窗口会停止预览并清空旧画面。
刷新保留同分辨率下的选区，画面尺寸改变则清空，避免沿用错误区域。

“整个桌面”包含全部显示器，复制的坐标和框选区域为 Windows 桌面物理像素，
左侧或上方副屏可以出现负坐标。预览缩放不改变坐标。
Windows 客户区预览优先使用 Windows Graphics Capture，可在目标被其他窗口遮挡时
继续取帧。系统或目标不支持时自动回退桌面截图，状态栏会提示；此时请保持目标
无遮挡。整个桌面预览仍会包含本工具，单次桌面截图会暂时隐藏本工具。
USB 和网络 ADB 均读取设备原始截图，不依赖电脑上手机窗口的显示大小。

## Windows 客户区

1. 在“截图来源”选择“Windows 客户区截图 / 客户区坐标”。
2. 刷新并选择目标窗口，或输入十进制 / 0x 十六进制 HWND 后点击“读取句柄”。
3. 点击 Screenshot，或开启实时预览。客户区优先进行无遮挡捕获；回退桌面截图时，
   单次截图会暂时隐藏本工具。
4. 移动鼠标查看客户区坐标；关闭框选后单击取点。
5. 勾选框选，拖动鼠标得到 (x,y,宽,高)。框选不会发送点击。
6. 点击“复制截图信息和选区”，将 HWND、客户区大小、屏幕原点、坐标及选区一起提供。
   “保存原始截图”可以导出未缩放的 PNG。

客户区截图不包含标题栏和外边框，但包含客户区内部的工具栏和黑边。
坐标原点为客户区左上角，单位为原始物理像素。Windows 缩放和工具预览大小
不会改变该坐标含义；调整目标窗口大小后，需要重新截图及框选。

预览画面可用鼠标滚轮以指针位置为中心缩放（100%～1600%），中键拖动画面，
点击“适合窗口”恢复全图。取点和框选仍返回原始截图像素坐标。
PC 点击与 ADB 点击使用独立坐标框。PC 输入默认使用前台 SendInput；也可选择
后台 PostMessage 或限时 SendMessage，发送鼠标点击、按键和文本消息，不主动激活窗口。
后台键盘消息发送给目标窗口当前焦点子控件，没有焦点时发给绑定窗口。后台模式仅表示
消息已送达，目标程序可能忽略消息；游戏、提权窗口及自行读取设备输入的程序需实测。

本工具独立于老板客户端运行，取坐标不会自动修改老板流程的 OCR 区域。
