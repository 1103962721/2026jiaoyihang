# 服务端高度与发送顺序控件修正设计

## 目标

修正服务端 850×650 窗口导致内容纵向拥挤的问题，并将错误实现为下拉框的发送顺序控件恢复为确认稿中的两个平铺单选项。

## 设计

- 服务端默认尺寸调整为 850×760，最小尺寸调整为 790×700。
- 客户端表格最小高度调整为 160px，日志区最小高度调整为 120px，保留现有纵向伸缩。
- 将 `triggerOrderCombo_` 替换为 `coinFirstRadio_` 与 `bossFirstRadio_` 两个 `QRadioButton`。
- 默认选中“币号 → 老板”；单选状态变化继续调用 `updateFlowPreview()`，不改变发送顺序的业务语义。
- 客户端列表中的币号/老板备注类型仍使用下拉框，不在本次修改范围内。

## 验证

- UI 契约测试先验证旧实现失败，再验证新尺寸、单选控件和日志空间。
- 执行相关 Python 回归、Release x64 服务端构建、编码及换行检查。
- 将新服务端 EXE 发布到 `Relase`。
