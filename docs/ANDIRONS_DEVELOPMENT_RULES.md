# Andirons 分支开发规则

这些规则适用于 `Andirons` 分支后续的设计、修改、评审和编译工作。

1. 本分支的修改只能新增功能或增加兼容能力，现有功能和既有行为必须保持不变。
2. 本次及后续 ADB/云手机兼容工作只修改老板执行的完整流程。
3. 币号的现有执行流程禁止修改。任何因为共享接口、协议、状态模型或其他原因可能影响币号执行流程的改动，必须先向用户说明影响范围并再次获得明确确认后才能实施。
4. 每次修改后都要分别验证老板流程和币号流程，确认币号流程没有发生行为变化。

## 实施边界

- 可以新增 ADB 设备会话、截图、点击、键盘、滚轮和 OCR 适配能力。
- 可以为老板流程增加 Windows/ADB 的兼容后端和独立状态。
- 不得为了复用老板流程而直接重构或改写币号流程。
- 新增共享代码必须保证默认路径仍使用原有 Windows 行为。

## ADB 客户端身份

- 一个 ADB 端口对应一个独立客户端；同一台电脑上的多个端口必须在服务端列表中分别显示。
- 客户端 EXE 内嵌官方 Platform-Tools 33.0.2 的 adb.exe、AdbWinApi.dll、AdbWinUsbApi.dll 和 NOTICE.txt；未配置外部 ADB 时自动释放到本机用户数据目录 DF_PlayClick/adb/33.0.2，分发时无需另装 ADB。保留有效 INI 自定义路径及同目录 ADB 的优先级，不依赖开发电脑绝对路径。
- 每个 ADB 客户端独立保存连接、执行、停止、资金、账号、角色和备注状态。
- 对一个 ADB 端口执行右键操作时，不得影响其他端口对应的客户端。

## 云手机坐标与本机 OCR 规则

- 云手机 ADB 老板 OCR 使用绑定 HWND 的 Windows 客户区截图，按客户区原点转换到桌面后截取可见像素，不再读取 ADB 设备截图。窗口必须可见、未最小化且客户区完整位于桌面内；其他窗口遮挡会进入截图。
- OCR 基准为客户区物理像素 737×440，不包含系统标题栏和边框。所有局部区域由用户提供，不能拿手机坐标代替。
- 绑定时固定所选客户区为 737×440；去掉所属顶层窗口的标准缩放边框和最大化按钮，并异步检查自定义缩放。窗口仍可移动，退出/移除会话/重新绑定时恢复原来的缩放样式。
- 截图时重新获取客户区大小和屏幕原点，不使用固定屏幕位置或硬编码 HWND。窗口尺寸尚未恢复时拒绝截图，不识别过渡尺寸，不静默回退 ADB 截图。
- 若绑定的是子客户区，通过调整所属顶层窗口让该子客户区达到基准大小；同一顶层窗口禁止被多个 ADB 会话同时锁定。
- 价格提示文字仍 OCR 整个 Windows 客户区；两处 X/N 区域裁剪后继续放大 3 倍。
- ADB 老板查找“仓库”及失败后重试时，将局部区域 (336,387,192,34) 放大 3 倍再识别；仍要求匹配“仓库”，点击坐标保持 (896,666)。
- ADB 点击、移动、键盘输入保持手机 1280×720 坐标，与本机 OCR 坐标独立。
- 每个端口绑定自己的 HWND，临时 OCR 文件不能互相覆盖。
- 本次变更只影响云手机 ADB 老板流程；PC 老板、币号及账号流程保持不变。
- 下架确认后继续识别上架数量：X>0 时再次执行两次下架点击，OCR 失败时继续读取数量，只有 X=0 才进入减价重上架。保留每次下架点击后 1500ms 等待及数量轮询 300ms 间隔。
- 首次上架保留价格面板 X!=1 检查；下架后的减价重上架仍打开价格面板，但跳过 X!=1 检查，继续输入和校验价格。
