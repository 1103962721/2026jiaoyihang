# Andirons 分支开发规则

这些规则适用于 `Andirons` 分支后续的设计、修改、评审和编译工作。

1. 本分支的修改只能新增功能或增加兼容能力，现有功能和既有行为必须保持不变。
2. 本次及后续 ADB/云手机兼容工作只修改老板执行的完整流程。
3. 币号的现有执行流程禁止修改。任何因为共享接口、协议、状态模型或其他原因可能影响币号执行流程的改动，必须先向用户说明影响范围并再次获得明确确认后才能实施。
4. 每次修改后都要分别验证老板流程和币号流程，确认币号流程没有发生行为变化。

## 实施边界

- 可以新增 ADB 设备会话、截图、点击、键盘、滚轮和 OCR 适配能力。
- 可以为老板流程增加 Windows/ADB 的兼容后端和独立状态。
- 不得为了复用老板流程而直接重构或改写币号流程。
- 新增共享代码必须保证默认路径仍使用原有 Windows 行为。

## ADB 客户端身份

- 一个 ADB 端口对应一个独立客户端；同一台电脑上的多个端口必须在服务端列表中分别显示。
- 每个 ADB 客户端独立保存连接、执行、停止、资金、账号、角色和备注状态。
- 对一个 ADB 端口执行右键操作时，不得影响其他端口对应的客户端。

## 云手机设备坐标与 OCR 规则

- ADB 老板流程通过对应端口执行 `exec-out screencap -p` 获取设备原始截图，不依赖 Windows 窗口或桌面截图。
- OCR 局部区域直接使用手机截图像素坐标，原点为设备图像左上角；当前手机为 1280×720，不再使用 704×430 映射。
- 全屏 OCR 使用设备截图的实际完整尺寸。旧的局部 OCR 数值需要用户重新提供或明确确认，不能擅自转换。
- ADB 点击和移动坐标使用手机 1280×720 坐标，原点为手机屏幕左上角。
- 每个端口独立截图和执行输入，临时图片不能互相覆盖。
- 本次变更只影响云手机 ADB 老板流程；PC 老板与币号的截图、坐标和输入流程保持不变。

## 已确认的 ADB OCR 手机像素区域

- 资金（准备、价格提示后、返回后）：`(966,42,224,103)`。
- 价格面板 X/N：`(1065,312,161,67)`。
- 输入价格校验：`(854,451,299,43)`。
- 可选上架确认：`(839,548,307,62)`。
- 上架数量 X/N：`(120,52,146,45)`。
- 格式为 `(x,y,宽,高)`，直接裁剪设备原图；两处 X/N 裁剪后仍放大 3 倍送 OCR。
