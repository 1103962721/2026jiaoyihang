# Andirons 分支开发规则

这些规则适用于 `Andirons` 分支后续的设计、修改、评审和编译工作。

1. 本分支的修改只能新增功能或增加兼容能力，现有功能和既有行为必须保持不变。
2. 本次及后续 ADB/云手机兼容工作只修改老板执行的完整流程。
3. 币号的现有执行流程禁止修改。任何因为共享接口、协议、状态模型或其他原因可能影响币号执行流程的改动，必须先向用户说明影响范围并再次获得明确确认后才能实施。
4. 每次修改后都要分别验证老板流程和币号流程，确认币号流程没有发生行为变化。

## 实施边界

- 2026-10-14 起 Andirons 客户端发布文件名使用 DF_PlayClick_Client_Qt_Andirons_1.x.exe，从 1.0 开始，每次发布 x+1。使用 publish_andirons_client.ps1，校验新成品 SHA256 后删除上一版同系列客户端；版本记录保存在 Relase/DF_PlayClick_Client_Qt_Andirons.version.json。通用稳定版、PCsoftf、服务端及其他工具不在清理范围。
- 两个 ADB 价格提示入口清理成功后，最多检查 5 秒、间隔 150ms：先在 (54,6,168,51) 找“一键配装”，命中直接识别资金并上报；否则在 (41,0,282,54) 找“装备配置”，命中则点击 (790,665)、等待 1000ms，再查找一键配装并点击 (116,315)、等待 1000ms，之后识别资金并上报。两个区域都未命中则直接识别资金；同轮都命中时一键配装优先。不得在旧区域 (324,377,211,53) 用“方案／仓库／配装”宽泛匹配。实际 OCR/ADB 错误、取消或导航后一键配装超时仍终止。历史变体见 `docs/ADB_PRICE_PROMPT_VARIANT.md`；正常返回准备界面的流程不变。

- 2026-10-14 用户明确授权的 PC 修复例外：PC 老板及普通上架流程的售位 OCR 区域改为 (1786,608,292,115)，基准 2560×1440，保留 X!=1 判断；保存配装武器、背包、蛋挂首次找到后等待 3000ms，重新截图识别并使用最新位置点击，复查未找到则继续原上下滚动分支。ADB 领取收益沿用现有超时重试循环。

- 可以新增 ADB 设备会话、截图、点击、键盘、滚轮和 OCR 适配能力。
- 可以为老板流程增加 Windows/ADB 的兼容后端和独立状态。
- 不得为了复用老板流程而直接重构或改写币号流程。
- 新增共享代码必须保证默认路径仍使用原有 Windows 行为。

## ADB 客户端身份

- 一个 ADB 端口对应一个独立客户端；同一台电脑上的多个端口必须在服务端列表中分别显示。
- 客户端 EXE 内嵌官方 Platform-Tools 33.0.2 的 adb.exe、AdbWinApi.dll、AdbWinUsbApi.dll 和 NOTICE.txt；未配置外部 ADB 时自动释放到本机用户数据目录 DF_PlayClick/adb/33.0.2，分发时无需另装 ADB。保留有效 INI 自定义路径及同目录 ADB 的优先级，不依赖开发电脑绝对路径。
- 每个 ADB 客户端独立保存连接、执行、停止、资金、账号、角色和备注状态。
- 对一个 ADB 端口执行右键操作时，不得影响其他端口对应的客户端。

## 云手机坐标与本机 OCR 规则

- 云手机 ADB 老板 OCR 使用绑定 HWND 的 Windows 客户区截图，按客户区原点转换到桌面后截取可见像素，不再读取 ADB 设备截图。窗口必须可见、未最小化且客户区完整位于桌面内；其他窗口遮挡会进入截图。
- OCR 基准为客户区物理像素 737×440，不包含系统标题栏和边框。所有局部区域由用户提供，不能拿手机坐标代替。
- 绑定时固定所选客户区为 737×440；去掉所属顶层窗口的标准缩放边框和最大化按钮，并异步检查自定义缩放。窗口仍可移动，退出/移除会话/重新绑定时恢复原来的缩放样式。
- 截图时重新获取客户区大小和屏幕原点，不使用固定屏幕位置或硬编码 HWND。窗口尺寸尚未恢复时拒绝截图，不识别过渡尺寸，不静默回退 ADB 截图。
- 若绑定的是子客户区，通过调整所属顶层窗口让该子客户区达到基准大小；同一顶层窗口禁止被多个 ADB 会话同时锁定。
- 价格提示文字仍 OCR 整个 Windows 客户区；两处 X/N 区域裁剪后继续放大 3 倍。
- 资金的准备检查、提示清理后、返回后三处统一使用 (495,64,192,72)，裁剪后放大 1.5 倍，以 288×108 像素送入 OCR。
- ADB 老板查找“仓库”及失败后重试时，将局部区域 (336,387,192,34) 放大 3 倍再识别；仍要求匹配“仓库”，点击坐标保持 (896,666)。
- ADB 点击、移动、键盘输入保持手机 1280×720 坐标，与本机 OCR 坐标独立。
- ADB 识别到“转移全部”后等待 1000ms，再点击 (457,664)；等待期间可停止动作。
- ADB 价格输入后等待 500ms，再在约 1500ms 校验窗口内每隔 150ms 重新 OCR；匹配目标价格才继续，不因第一次读到不完整数字立即清空。超时不一致才重新输入，最多 3 次；PC 价格输入不变。
- 每个端口绑定自己的 HWND，临时 OCR 文件不能互相覆盖。
- 仅 ADB 模式的取窗和列表允许任意应用窗口（含无标题窗口），不限制进程或标题；用户自行确认目标是否正确。保留 VM/PlayUI 实际画面的客户区选择能力，同一窗口不能重复分配到不同端口。
- 按住“拖动绑定窗口”拖至目标时显示蓝色外围框，松开弹出“是否确定绑定”是/否提示；选是后输入 ADB 端口，完成后才添加会话。选否、取消端口或 Esc 不绑定，不改变窗口尺寸；保留原列表选择方式。
- 尺寸修正不得因连续重试超过 15 次而解除锁定。每个会话独立维护尺寸定时器，临时调整失败保留锁并重试，关闭窗口或移除会话才释放；移除第二个会话不得解除第一个窗口的限制。
- 本次变更只影响云手机 ADB 老板流程；PC 老板、币号及账号流程保持不变。
- 下架确认后继续识别上架数量：X>0 时再次查找下架，OCR 失败时继续读取数量；查找区域识别到“等待上架”时直接进入原减价重上架流程，不能把 OCR 的 8 一律当作 0。下架查找超时则回查数量：X=0 按是否实际下架决定重上架或领取，X>0 继续查找。保留每次下架点击后 1500ms 等待及数量轮询 300ms 间隔。
- 首次上架保留价格面板 X!=1 检查；下架后的减价重上架仍打开价格面板，但跳过 X!=1 检查，继续输入和校验价格。
- 价格面板使用 (598,202,124,49) 客户区区域，裁剪后放大 3 倍；该步骤可解析分母缺失的“使用售位：6/”或“6/”，只使用当前值 X，X=1 仍不得继续。上架数量归零解析不使用这一兼容规则。
- 任一价格提示检查入口发现提示后，ADB 点击 (802,50)、等待 1500ms 并复查，约 3 秒内确认清理成功后进入上述局部文字分流判断，再识别稳定资金、上报金额和准备状态，并结束本轮；仓库失败后的提示清理也遵循此规则，只有未发现提示时才继续查找仓库。
- 进入领取阶段后等待 500ms，再点击 (516,79)；保留点击后 2000ms 等待和“领取完成”最长 5 秒、间隔 150ms 的检查。仅识别超时则重复等待、点击和检查；停止动作或实际 ADB、窗口、OCR 错误时退出，不继续点击。

## 已确认的 Windows 客户区 OCR 区域（737×440）

- 领取完成后的确认点击为 ADB 手机坐标 (67,119)，前后各等待 1500ms；返回 (29,34) 后等待 500ms。出发查找超时则在 (50,0,231,54) 查找交易行，最长 5 秒、间隔 150ms；找到才再次返回并等待 500ms，两者都未找到则不点击并重新查找出发，循环至找到或取消/实际错误。OCR 排队计时不变。
